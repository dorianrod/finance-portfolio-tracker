# Enforced function-complexity review — 26 October 2026

The complexity limit remains 8 (modified variant) and is enforced as an error. Every reported body and its call context was reviewed using the Dorian rule. The import/module split does not change the financial algorithms or accessibility protocols.

Three useful boundaries were extracted: the overview driver display model, overview concentration rows, and separate account, period and operation filter summaries. The concentration chart also reuses its description instead of selecting the same text twice. These functions and their new helpers now meet the threshold.

The following functions keep a single cohesive responsibility. Their exceptions are on the reported line only and name the reason, so new functions and unrelated callbacks remain subject to the error threshold. Optional-chain and default-value branches count even when they implement one payload or primitive contract; they do not automatically justify fragmenting that contract.
