# UI, accessibility, composition and internationalization review

The source pattern inventory accounts for project component APIs and dependency renderers. Public ControlProps removes raw ARIA, keyboard/focus and layout escape props; domains pass meaning, actions and labels. Shared Radix adapters own wiring. ExternalLink, Button, Tooltip, Popover, Preview, SidePanel and navigation protocols have role/label interaction tests. Event composition tests cover caller invocation, cancellation after forwarding, read-only DOM metadata, refs and noncancelable value notifications. Preview/Popover tests exercise outside dismissal then keyboard reopening, Escape, forward/backward Tab and unavailable targets. Conditional native forwarding used only after read-only DOM metadata is supported by the existing contract/calibration; it is not an unproven new violation.

Compound roots use partitionSlot or dependency slot APIs. Direct slots remain renderable and present at their root; extracted content sits inside slots. Required UI content uses children; dependency-required tooltip/tick/shape/render configurations refer to module-scope named renderers. Scalar labels, formatters and business callbacks are data/configuration. Dialog SidePanel remains mounted with controlled open; there are no submit forms or nested forms.

Domain appearance is supplied by shared semantic variants; only external layout classes remain outside shared UI. Shared UI and theme tokens have no portfolio vocabulary in production APIs or indirect helpers; financial KPI accents reside in portfolio scoped shared code. Theme/index.css defines concrete values, shared UI consumes semantic tokens, static assets are separate. Generic closed spacing/layout tokens implement internal structure. Style/literal-color/internal-layout probes pass through the actual config. Existing story examples build and their assertions exercise slots.

Heavy tabs use a finite literal loader registry, lazy at module scope, intent preloading with handled rejection and a retained shell error boundary. Build output has separate optional tab chunks. Held positions/exposure behavior uses virtual rows; no evidence warrants extra containment/transitions. Controlled search updates remain immediate and are not wrapped in external-store transitions.

Catalog usage, missing/static-key/interpolation/default/copy checks pass. There is one English catalog. Component translations/static heading getters are valid UI copy. F-001 instead converts domain dimension/status values to labels outside formatter hooks. Provider-specific regressions will check the actual unit-label behavior. Literal source data/technical acronyms and decorative glyphs are not translated sentences; API-provided messages remain readable data.
