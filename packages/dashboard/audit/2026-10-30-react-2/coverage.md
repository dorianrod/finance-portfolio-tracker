# Audit coverage

## File review

All 1,318 inventoried authored/supporting inputs are listed individually in [file-review.md](evidence/file-review.md), with machine-readable [rows](evidence/file-review.json) and [SHA-256 manifest](evidence/files.json). There are 1,293 parsed JS/TS modules, 263 application/integration tests, 94 features, 241 views and two state renderers. [Target groups](evidence/target-groups.json) enumerate exact eligible files instead of directory/count-only claims. Group lists overlap.

All 1,309 preceding final source hashes and all 239 preceding contract/configuration hashes match. The unchanged prior [file reconciliation](../2026-10-30-react/evidence/phase2-file-review.md), [semantic review](../2026-10-30-react/evidence/phase2-semantic-review.md) and original per-file/rule evidence are explicitly carried forward where relevant. This audit adds fresh global gates, AST/caller inventory, configured calibration, selected source/UI/filter/schema traces and a full investigation of testing candidates. It does not claim a fresh line-by-line read of every unchanged file. Prior reviews are evidence, not authority overriding concrete contradictory code: F-001 and F-002 correct missed testing obligations.

All 43 current architecture candidates match the prior final candidate tuples and retain their semantic dispositions in [architecture-review.json](evidence/architecture-review.json). Every current feature has an explicit [boundary decision/provenance](evidence/feature-boundaries.json). The two state renderers and their builders were freshly reviewed. Supporting workflows, ignore/formatter/package policy, HTML bootstrap, canonical theme tokens and [asset references](evidence/asset-review.json) are accounted for. Python code, generated output/vendor/data and other audit dossiers are excluded rather than declared conforming.
