# Rule Routing

This focused table covers business boundaries and stricter UI conventions. Use it to select candidate rule files from observable code patterns or an explicit review intent. Then read the selected files and confirm their applicability and exceptions.

Routing rules:

- Load the files linked by matching signals and select any additional relevant topics from the Quick Reference.
- When several distinct signals match, load every corresponding file.
- Prefer the most specific signal when routes overlap.
- A keyword alone is not a match unless its route explicitly says so.
- For topics not listed here, select relevant rule files from the Quick Reference in SKILL.md.
- Files beginning with `_` are maintenance material, not active rules.
